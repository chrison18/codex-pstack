# Phase 1 entry evidence

Status: in progress. These checks establish an installable preview and host loading policy, not the phase 1 desktop exit gate or phase 2 core workflows.

## Scope

The Codex marketplace distributes only `plugins/pstack/`, version `0.1.0-alpha.1`. Its single skill is a preview availability response. The original 59 skills, 2 agents, 23 playbooks, and 3 Benny skills remain migration source; none is implicitly included in this package. The upstream MIT license is included unchanged.

No personal settings, auth, timers, or persistent agents were installed during the checks. CLI probes used temporary `CODEX_HOME` directories and disposable workspaces.

## Reproduce

```sh
bun scripts/validate-codex-plugin.ts
bun test scripts/validate-codex-plugin.test.ts
python3 scripts/smoke-codex-entry.py
```

The smoke script starts a loopback HTTP capture endpoint and temporarily directs a disposable Codex session to it. It observes Codex's actual outgoing context, then terminates the session without obtaining a model response. The configured model name is a local test request field; no paid model or API credential is used. The script checks real host injection rather than relying on skill self-report.

The app-server check used the schema generated by the installed Codex executable and a disposable stdio server. It validates the backend used by local clients; it is not proof that a user has completed the desktop UI flow.
