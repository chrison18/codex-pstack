# Poteto mode

This is the staged Codex core workflow. Read [status](references/status.md) when asked about availability; report the verified scope and remaining evidence limits. Bounded named-task checkpoint/recovery is available below, with fresh Orca Chat pickup evidence; automatic wake and autonomous workflows remain unavailable.

Activate only on explicit invocation for a new task. Follow-ups continue that active task. Installing this plugin or roles does not activate the workflow for ordinary new prompts. The primary chat owns the playbook, checklist, delegations, evidence and final answer.

Read [the runtime contract](references/runtime.md) before executing a task or configuring roles. Read only the applicable playbook. Select and read the full applicable leaves through the [principle index](references/principles.md):

- Pause, named-task recovery or conservative worktree audit: [task checkpoint and pickup](references/session-lifecycle.md).
- Parallel coverage, races and isolated code slices: [Swarm](references/swarm.md).
- Independent alternatives and synthesis: [Arena](references/arena.md); structural design and implementation: [Architect](references/architect.md).
- New or changed behavior: [Feature](references/feature.md).
- Reported defect: [Bug fix](references/bug-fix.md).
- Read-only adversarial code review: [Interrogate](references/interrogate.md), within the [Investigation](references/investigation.md) no-mutation boundary.
- Read-only explanation or recommendation: [Investigation](references/investigation.md), then [How](references/how.md) for mechanics or [Why](references/why.md) for historical motivation.

For writing, quality, app control, verification authoring/maintenance, prototype, refactoring, performance, evaluation, planning or PR delivery, read the [workflow index](references/workflow-index.md), select its matching reference and follow its dependencies. Do not load every leaf for an ordinary task.

For activated multi-step work with side effects, read [task checkpoint and pickup](references/session-lifecycle.md) and establish its task record before those effects; keep requirements, evidence and next action current without waiting for the user to request a pause. For small read-only work, use a concise response capsule; if durable writes are forbidden, keep that boundary and disclose the lack of durable recovery rather than writing implicitly. Create and update the playbook checklist; retain skipped steps with reasons. Delegation prescribed by the selected route is part of that explicitly invoked workflow, subject to host permissions and the user's scope. Pass this file's absolute path to `poteto-agent` and `comment-sicko`; inspect returned evidence yourself. Never delegate ownership of the full workflow.

For model setup, follow the runtime contract's configure/resolve commands only when requested. Do not load the inherited Antigravity tree, mutate global configuration or install project roles as a side effect of an ordinary task. Missing role/tool/model support must be reported before claiming that step completed. Phase 5 autonomous/recurring execution remains unavailable.
