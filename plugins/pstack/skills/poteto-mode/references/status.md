# Codex preview status

This package contains one explicitly invoked entry, `$poteto-mode`. Installation, discovery, invocation policy, and removal are the phase 1 validation targets. It does not yet implement task routing, custom agents, model configuration, persistent checklists, or autonomous work.

The source repository tracks pstack 0.15.29 and cursor-team-kit 1.2.0. Those versions identify inherited source content, not this preview's supported runtime. This Codex package has its own version, 0.1.0-alpha.1.

Phase 2 adds core task execution. Later phases migrate parallel workflows, session recovery, and automation. Do not substitute another host's tool names or scripts for missing Codex behavior.
